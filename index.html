Fare Construction & Currency Rounding

NUC → Local Currency Rounding, Explained

When an airfare is constructed across countries, IATA builds it in a currency-neutral unit first, then converts it back into real money using a fixed rule. This page walks through that process end to end.

Glossary

NUC — Neutral Unit of Construction
A fictitious currency used only inside the fare-construction formula, so amounts from different countries can be added together. Always carried to 2 decimal places (truncated, never rounded, until the final step).
ROE — Rate of Exchange
The official IATA factor that converts a NUC total into the local currency of the country where travel begins. Published by IATA (Passenger Resolution 024c) and updated periodically — always use the rate in effect on the ticket issue date.
Rounding Unit (RU)
Each currency has an official "step size" it must round to (e.g. 1, 0.10, 0.05, 100). Fare amounts are always rounded up to the next RU step — never rounded to nearest, never down.
GI — Global Indicator
A 2-letter code (e.g. EH) marking which geographical routing/direction a fare applies to. It determines which mileage table (MPM) governs the itinerary.
MPM — Maximum Permitted Mileage
The maximum mileage IATA allows between two fare construction points before an excess mileage surcharge applies.
TPM — Ticketed Point Mileage
The actual flown distance between two ticketed points, checked against the MPM.
Fare Basis / Rule code (e.g. Y974)
An alphanumeric tag identifying the specific filed fare and its rule record. The leading letter (e.g. Y) marks the class of service/fare type; the digits point to the rule.
OW / RT
One Way / Round Trip fare.
Note on "FIF": this isn't a term with a single universal IATA meaning — it appears to be specific to the course/GDS material this example came from. Rather than guess and risk teaching the wrong definition, check the legend on the original worksheet/course page it came from.

The rounding rule

  1. Add up the fare construction in NUC.
  2. Multiply the NUC total by the ROE for the currency of the country where the journey starts.
  3. Carry the result one decimal place beyond the currency's rounding unit.
  4. Round up to the next rounding unit — even if the excess is just 0.01.
